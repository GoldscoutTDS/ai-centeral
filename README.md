# AI Central

A simple, responsive directory for discovering AI tools.

## Features
- Search tools by name, category, or description
- Filter by Chatbots, Image Generation, Video, Coding, and Research
- Open each tool's official website in a new tab
- Responsive dark-themed layout for desktop and mobile

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will provide the public website link once deployment finishes.

AI Central is an independent directory. Tool names and descriptions are provided for discovery; check each official website for current features and availability.
